## 回来要做的事

因为用量达到上限停下时，这一节最前面先写：停在 T<n> 的哪一步、它的 stash 名、还没开始的任务，以及接着做的提示词（单独一行，可以直接粘贴）：`/unattended <任务书路径> 继续 <运行号>`。汇总的最后一行再重复一次这句提示词。

1. 先看“重点复核”，再审阅提交：`git log <原分支>..auto/<运行号>`。
2. 满意的合并进原分支并推送（这两步由你执行）；不满意的可以整个丢掉这个分支。只想要其中几个任务时，用 `git cherry-pick <提交号>` 挑到原分支上，留意上面列出的重叠文件。
3. 失败的任务：`git stash list` 找到对应的改动，决定接着修还是丢弃。
4. 登记为“待复核”的例外、第三方命中、决策：确认后把批准人改成你自己，或者删掉并改代码。
